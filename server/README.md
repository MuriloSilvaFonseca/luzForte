# Backend Futuro

Esta pasta está reservada para a futura implementação do backend em Node.js.

Estrutura sugerida:

- `src/controllers`: recebe as requisições e coordena as respostas.
- `src/models`: representa as entidades do sistema, como usuário, produto e pedido.
- `src/routes`: define as rotas da API.
- `src/services`: concentra regras de negócio.
- `src/config`: armazena configurações da aplicação.
- `src/middlewares`: contém validações intermediárias.
- `src/database`: futura conexão com banco de dados.
- `src/utils`: funções auxiliares.
- `tests`: testes automatizados do backend.
