# LuzForte

LuzForte é um projeto acadêmico de e-commerce/catálogo digital de materiais elétricos, desenvolvido inicialmente com HTML, CSS e JavaScript.

## Objetivo

O objetivo do sistema é permitir que usuários consultem materiais elétricos, visualizem detalhes dos produtos e simulem a montagem de um carrinho de compras. Nesta etapa, o projeto não possui backend, banco de dados ou pagamento real.

## Estrutura

- `index.html`: entrada principal do projeto.
- `src/pages`: telas do sistema.
- `src/styles`: arquivos CSS.
- `src/scripts`: arquivos JavaScript.
- `src/components`: componentes reutilizáveis.
- `src/assets`: imagens, ícones, logotipos, fontes e vídeos.
- `docs`: documentação acadêmica e técnica.
- `server`: estrutura reservada para futura API em Node.js.
